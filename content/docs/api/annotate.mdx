---
title: "onInkAwayAnnotate"
description: "Open annotation using Ink Away\u2019s existing action."
---

Call this from your own annotation button or menu action after connecting.
Ink Away selects the visible registered viewer; otherwise it uses the native reader.

```lua
if self.ink and self.ui.inkAwayIntegrationAPI == self.ink then
    self.ink:onInkAwayAnnotate()
end
```

## Arguments

None.

## Returns

`true`: the action was handled. This does **not** confirm that the editor opened.
Use [onAnnotationOpened](/docs/api/on-annotation-opened) or a scoped `on_open`
callback when you need confirmation.

## Things to know

- No open book means no editor, even though the return value is `true`.
- Requesting an already-shown editor does not open a second one.
- Read-only annotation data or initialization failures can prevent opening.
- Rendering factories are evaluated when a new session opens, not when registered.
