---
title: "Event-only consumer"
description: "React to annotation opening and closing. No viewer or surface is needed."
---

This example pauses your plugin's work while the reader is annotating, then
lets it resume. It listens to sessions in both the normal reader and custom viewers.

`YourPlugin` is your plugin object. The helper names below belong to the example:
call `self:connectInkAway(self.ui)` from your own reader setup, and `self:dispose()` from
your teardown. They are not required KOReader lifecycle signatures.

## 1. Connect when your reader opens

```lua
function YourPlugin:connectInkAway(ui)
    self.ui = ui
    self.closed = false
    if ui.inkAwayIntegrationAPI then
        self:configureInkAway(ui.inkAwayIntegrationAPI)
    else
        ui.inkAwayPendingIntegrations = ui.inkAwayPendingIntegrations or {}
        ui.inkAwayPendingIntegrations[self] = true
    end
end
```

If Ink Away is already ready, configuration happens immediately. If it loads
later, it removes your queue entry and calls your method. You do not need to
look up `ui["ink-away"]` or control plugin loading order.

## 2. Subscribe in configureInkAway

```lua
function YourPlugin:configureInkAway(ink)
    if self.closed or self.stop_open then return end
    if ink.integration_api_version ~= 1 then return end

    self.stop_open = ink:onAnnotationOpened(function(event)
        self.annotation_open = true
        self.annotation_document = event.document
        -- Pause your plugin's work here.
    end)
    self.stop_close = ink:onAnnotationClosed(function()
        self.annotation_open = false
        self.annotation_document = nil
        -- Resume your plugin's work here.
    end)
end
```

Keep the two returned functions: calling them unsubscribes your listeners.
`event.document` identifies the book. `event.surface` is `nil` for the normal
reader, or a surface table for a custom viewer. Events describe future openings
and closings; subscribing does not replay a session already in progress.

## 3. Disconnect when your owner closes

```lua
function YourPlugin:dispose()
    if self.closed then return end
    self.closed = true
    local pending = self.ui.inkAwayPendingIntegrations
    if pending then pending[self] = nil end
    if self.stop_open then self.stop_open() end
    if self.stop_close then self.stop_close() end
    self.stop_open, self.stop_close = nil, nil
end
```

Removing the queue entry cancels a connection that has not happened yet.
Unsubscribing stops an existing connection. An event-only consumer does not
close an editor or release another plugin's surface.
