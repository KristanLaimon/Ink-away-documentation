A plugin may use **both** roles. Event-only subscriptions observe all sessions
on one reader, including the native viewer. Rendering providers supply geometry
and painting for their own viewer; Ink Away retains tools and persistence.

Start with the [connection walkthrough](/docs/integration/overview), then read
[loading order and disposal](/docs/integration/loading-order). The examples are
reader-scoped mocks and use `consumer:configureInkAway(ink)` directly.
