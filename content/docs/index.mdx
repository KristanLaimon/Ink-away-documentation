Ink Away offers includes a public API that allows other plugins
to connect to it, and extend its functionality, like mods. This way is easier integrate other
plugins with Ink Away without messing its internals or having to "monkey-patch" it.

# What you can do?

Your plugin can subscribe and be notified of all "Ink-Away" important events like:
- Opening Annotator Book Layer
- Closing ********************
- Option to give him a custom view renderer.
- & more

So this Ink-away public API exposes events and methods to make that possible in first place.

# Useful nomenclature
Troughout this section, we'll be using the following terms:

- **`ui`** is KOReader's reader UI for the open book. In your plugin, this is
  normally `self.ui`.
- **`ink`** is the ready Ink Away plugin instance. Use it to call the public methods.
- **Consumer** means your plugin object, or the object that owns its integration.
- **Viewer** is your actual KOReader widget that displays content. Only rendering
  consumers need one.
- **Surface** is a Lua table that tells Ink Away how your viewer's screen positions
  map to the book's original page coordinates.
