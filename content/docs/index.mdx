Ink Away owns annotation tools, ink storage, undo, and export. Other plugins can
observe annotation sessions or supply a document rendering surface through a
versioned public API.

## Availability

These docs describe **integration API v1** and **document surface v1** on the
`feature/plugin-integration` branch of the Ink Away fork. Unmodified upstream
4.4.0 does not expose these interfaces. Check the API fields and methods you
need at runtime; a metadata release number alone is insufficient.

The API uses in-process Lua methods. Parameter and return tables follow an API
reference style; these are not HTTP endpoints.
